# Adoption observation plan

**Status:** unexecuted experiment plan  
**Implementation:** none  
**Network dependency:** none required by this plan  
**Related proposed ADR:** [ADR-JPUB-006](../decisions/adr-jpub-006-static-reference-library-and-exemplars.md)

The aim is to observe whether useful artifacts invite independent reuse, not to run a standards campaign or telemetry service.

## Separate questions

- Does a future dossier reduce recipient effort to find a claim, reproduce a bounded case, and decide disposition compared with an ordinary report of similar quality?
- Do independent authors create genuinely new, structurally compatible publications without direct solicitation?
- Does another person later imitate an independent adopter rather than the originating publisher?
- Does optional format machinery create enough friction that readers ignore otherwise useful evidence?

A format could aid review without spreading. Public observations cannot establish zero private use.

## Preregistration gate

Before any measured exemplar, freeze the observation window, discoverability method, indicators, thresholds, comparison plan, and reporting rule. Do not manufacture social proof or vary recipient treatment in a way that burdens maintainers. If a credible control is unavailable, report a case study rather than causal impact.

Stars, traffic, forks, and favorable comments are not sufficient evidence of independent authorship. Copying an example verbatim does not count as new use. Report attrition, confounds, negative outcomes, and the possibility that a useful practice should remain local rather than become a standard.
