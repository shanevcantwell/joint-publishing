# Cold-reader and attestation test plan

**Status:** unexecuted experiment plan  
**Implementation:** none  
**Network dependency:** none required by this plan

No test result, signature system, answer key, or passing fixture exists yet.

## Reader plan

Give unfamiliar human and agent readers a future fixture without chat history. Compare a no-tool group with a group allowed to inspect an optional, pinned reader contract. Ask each reader to identify the selected joint, claim status, strongest counterevidence, cheapest legitimate falsifier, safe execution preconditions, attestation scope, and allowed next action.

Freeze scoring criteria before collecting responses. Record time, review effort, omitted uncertainty, invented test results, and incorrect claims of authority. Include a misleading rendering paired with precise underlying evidence to test whether readers recover the evidence rather than repeat the framing.

## Future integrity and attestation cases

1. Exact fixture bytes pass a named digest check; one-byte mutation changes identity.
2. A valid statement by an unrecognized key reports key control without inferred trust.
3. Two authentic statements disagree without invalidating each other or the subject.
4. A claim-scoped statement cannot be displayed as endorsement of the whole publication.
5. A self-described human review cannot substitute for evidence of independent human work.
6. Missing offline definitions are reported separately from subject-byte integrity.
7. Key rotation, compromise, absent time evidence, and unavailable revocation evidence remain explicit.
8. Linked instructions cannot trigger installation, network access, or execution.

## Stop condition

If readers cannot recover the selected relationship and falsifiers without private explanation, revise the human entry point before broader format work. If a candidate signing approach needs hidden online services, document the dependency and reassess the static/offline boundary.
