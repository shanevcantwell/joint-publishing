# Examples

No public exemplar is included at founding.

An earlier candidate was excluded because its evidence, code state, recipient rules, and transport assumptions require revalidation. The founding tree does not preserve its private or recipient-specific body, commit identifier, issue identifier, tracker reference, or rendered contribution.

A future exemplar must pass all of these gates:

- source rights, provenance, attribution, and confidentiality review;
- current-code and current-recipient-rule review;
- bounded reproduction with honest negative and inconclusive results;
- alternatives and counterevidence review;
- recipient-controlled safety and transport authorization;
- exact-byte publication approval; and
- a no-install, offline cold-reader test.

One exemplar would demonstrate only its scoped usefulness. It would not validate the whole design, establish a universal standard, grant recipient authority, or prove independent adoption.
