# Tools

**Status:** design documentation  
**Implementation:** none  
**Network dependency:** none required by this document

No tool, validator, command, package, or executable is supplied.

Future tooling, if separately accepted, should keep two boundaries distinct:

- **Read-only inspection:** parse data, check exact bytes and references, and report supported attestation results without network access or execution.
- **Opt-in reproduction:** run only under recipient-controlled isolation, permissions, resource limits, and evidence capture.

Tool language, command names, packaging, release policy, and maintenance commitments remain unresolved. Documentation here is not an executable validation command or evidence that any test passed.
